# 📚 Ignite - Desafio 03: Blog com API do GitHub

## Introdução

Faala dev!

Seja muito bem-vindo(a) ao terceiro desafio da trilha de **ReactJS** do **Ignite**. Neste desafio, você terá a oportunidade de praticar a utilização de clientes HTTP consumindo a API do GitHub para criar um blog pessoal.

Como este desafio requer alguns conhecimentos além dos abordados neste módulo, é fundamental ter autonomia para pesquisar e resolver problemas por conta própria. Mantenha a calma e **acredite no seu processo**. O aprendizado adquirido aqui será extremamente valioso e você sairá deste desafio com muito mais conhecimento 💜.

## Sobre o Desafio

Neste desafio, você desenvolverá uma aplicação que utilizará a API do GitHub para:

- Exibir as informações do seu perfil, incluindo imagem, número de seguidores, nome e outras informações disponíveis pela API.
- Listar e filtrar todas as issues do repositório, exibindo um pequeno resumo de cada uma.
- Criar uma página dedicada para exibir um post (issue) completo.

Embora as funcionalidades sejam relativamente simples, será necessário relembrar e aplicar conceitos como:

- Fetch / Axios
- Roteamento com React Router DOM
- Manipulação de Formulários

Para concluir o desafio, será necessário realizar algumas pesquisas sobre a API do GitHub e preparar o ambiente de desenvolvimento.

## Desenvolvendo o Projeto

Para desenvolver este projeto, recomendamos utilizar as principais ferramentas abordadas no primeiro módulo do Ignite, tais como:

- React com Vite e TypeScript
- Axios para requisições HTTP
- react-hook-form para manipulação de formulários
- Entre outras bibliotecas que você já conhece

### Passo a Passo

1. Crie um repositório **público** no GitHub. Esse repositório será onde você criará `issues` que funcionarão como os posts do seu blog. Se preferir, você pode usar o mesmo repositório para armazenar o código da aplicação.

2. Cada `issue` terá como título o nome do post e o conteúdo do corpo da issue será o texto do post.

3. Para referência, você pode ver um exemplo de issue representando um post [neste link](https://github.com/rocketseat-education/reactjs-github-blog-challenge/issues/1).

## Ferramentas Utilizadas

- **React**: Biblioteca JavaScript para construção de interfaces de usuário.
- **Vite**: Ferramenta para desenvolvimento de front-end, focada em velocidade e desempenho.
- **TypeScript**: Superset do JavaScript que adiciona tipos estáticos.
- **Axios**: Cliente HTTP baseado em Promises para fazer requisições.
- **react-hook-form**: Biblioteca para gerenciamento de formulários em React.
