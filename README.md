## Sobre o Desafio

Neste desafio, desenvolvi uma aplicação que utiliza a API do GitHub para:

- Exibir as informações do meu perfil, incluindo imagem, número de seguidores, nome e outras informações disponíveis pela API.
- Listar e filtrar todas as issues do repositório, exibindo um pequeno resumo de cada uma.
- Criar uma página dedicada para exibir um post (issue) completo.

Embora as funcionalidades sejam relativamente simples, foi necessário relembrar e aplicar conceitos como:

- Fetch / Axios
- Roteamento com React Router DOM
- Manipulação de Formulários

Para concluir o desafio, realizei algumas pesquisas sobre a API do GitHub e preparei o ambiente de desenvolvimento.

## Desenvolvendo o Projeto

Para desenvolver este projeto, utilizei as principais ferramentas abordadas no primeiro módulo do Ignite, tais como:

- React com Vite e TypeScript
- Axios para requisições HTTP
- react-hook-form para manipulação de formulários
- Entre outras bibliotecas que já dominava

### Passo a Passo

1. Criei um repositório **público** no GitHub, onde criei `issues` que funcionam como os posts do blog. Este repositório também armazena o código da aplicação.

2. Cada `issue` tem como título o nome do post e o conteúdo do corpo da issue é o texto do post.

3. Para referência, usamos o exemplo de issue representando um post [neste link](https://github.com/rocketseat-education/reactjs-github-blog-challenge/issues/1).

## Ferramentas Utilizadas

- **React**: Biblioteca JavaScript para construção de interfaces de usuário.
- **Vite**: Ferramenta para desenvolvimento de front-end, focada em velocidade e desempenho.
- **TypeScript**: Superset do JavaScript que adiciona tipos estáticos.
- **Axios**: Cliente HTTP baseado em Promises para fazer requisições.
- **react-hook-form**: Biblioteca para gerenciamento de formulários em React.
